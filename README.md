# 爆款解码器（viral-decoder）

> 把任意抖音账号的口播内容，批量扒成中文逐字稿，做成一份可以直接拿去对标、复刻的内容拆解报告。

一个给内容创作者、自媒体运营、一人公司用的 WorkBuddy Skill。输入抖音号或账号名，输出：

- **全账号中文逐字稿**（语音识别，逐条对应原视频，可闭环校验）
- **自包含 HTML 拆解报告**（标题公式 / 开头钩子 / 口播骨架 / 金句 / 引流漏斗 / 同类对比）
- **可直接照抄的执行结论**（每条结论回答"怎么用、怎么变成钱"）

已在 86 条作品的账号上完整跑通：86 条作品 = 86 条文案 = 86 张报告卡片，无缺无多。

---

## 一、为什么做这个

看对标账号，一条条刷视频、手动听写、记笔记，效率极低，而且记下来的东西散、没有结构。

这个 Skill 把这件事变成一条流水线：**采集 → 下载音频 → 语音转写 → 闭环校验 → 生成报告 → 深度分析 → 清理交付**。你只需要给一个抖音号，拿到的是一份能直接指导自己选题和脚本的拆解报告。

## 二、它能拆解什么

按 `references/analysis-framework.md` 的框架，报告覆盖：

| 维度 | 具体内容 |
|------|----------|
| 标题公式 | 从全账号标题提炼高频可复用公式（数字钩子、反常识、身份标签、痛点直击、悬念留白） |
| 开头钩子 | 前 3 秒的 5 种钩子类型，附原句 |
| 口播骨架 | 双人对话诊断式 / 清单体逐条式等结构拆解 |
| 金句库 | "XX 就是 XX"等可转发的命名化表达 |
| 引流漏斗 | 统一尾板、钩子词、从内容到私域的完整路径 |
| 同类对比 | 五维法（IP定位 / 流量来源 / 产品体系 / 商业模式 / 是否值得复制） |
| 可借鉴点 | 落到"这条路怎么变成钱"，不写空泛建议 |

## 三、安装与使用

### 安装

方式一：作为 Skill 安装

```bash
# 把 viral-decoder/ 整个目录放到 WorkBuddy 的 skills 目录
cp -r viral-decoder ~/.workbuddy/skills/
```

方式二：作为专家包安装（含更友好的对话入口）

下载本仓库 Release 里的专家包 zip，在 WorkBuddy 里通过「添加插件市场 / 导入」安装。

### 使用

对着 WorkBuddy 说：

- "用爆款解码器拆解这个抖音号 53828376631"
- "扒一下「一人公司百房计划-大哲」的中文文案，做内容分析"
- "提取这个抖音号的逐字稿，前 20 条就够"

详细工作流见 `viral-decoder/SKILL.md`。核心脚本用法：

```bash
python scripts/collect_ids.py <sec_uid> works.json --port 9223 --expected <作品总数>
bash scripts/launch_edge.sh 9223 ./_edge_profile     # 后台常驻
python scripts/batch_download.py works.json audios --port 9223 --results download_results.json
python scripts/build_report.py <报告.html> "<账号名>" <抖音号> <作品总数> transcripts/batch_*.txt
```

**必读**：`viral-decoder/references/lessons.md` 记录了踩过的坑（登录态、DASH 音频流、转录结果防丢、临时目录清理），不读会走回头路。

## 五、适用与不适用

**适用**：
- 想系统研究某个对标账号的内容创作者
- 做短视频运营、需要批量拆解爆款结构的团队
- 一人公司 / 个人 IP，要找"可复刻的内容公式"

**不适用**：
- 想承诺涨粉、出爆款的人——本报告只提供内容结构参考，不保证结果
- 想直接搬运、洗稿他人内容的人——输出仅用于学习研究
- 加密 / 私有视频、需要登录后台才能看的账号数据
