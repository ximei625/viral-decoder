# 内容分析框架（财商/知识口播类账号通用）

在「大哲」账号上提炼出的分析维度。生成报告时，WorkBuddy 手动完成第 3 节之后的分析，并把 HTML 片段通过 `build_report.py --sections-json` 注入报告。

## 一、6 大爆款标题公式（从 86 条标题统计提炼）

1. **数字钩子**：六个/八句/七种/十二条/四步/一万块/110套——标题带具体数字，降低理解成本、提高收藏率。
2. **反常识断言**：「穷人富相的女人迟早会很有钱」「赚钱不是运气是公式」——先打破预期再给答案。
3. **身份标签 + 结果公式**：潮汕人/富人/生意人/女人 → 暴富/赚钱/改命。
4. **痛点直击**：赔光积蓄、赚不到大钱、收入上不去、裸辞创业、人生卡死。
5. **悬念留白**：「最后一种千万别赚」「今天公开了」「记住这八句」。
6. **权威背书 + 玄学互动咒语**：「巴菲特/李嘉诚套现」「能刷到证明你要变富了」「评论区打我要发财」——制造被选中感，拉互动。

## 二、口播正文的通用骨架

> 数字/反常识钩子 → 诊断痛点或讲故事 → 分点给方法论（每点一个金句）→ 升华/重新定义 → **统一引流尾板**

- 常见形式：双人对话式（主角 + 配角提问）、清单体、故事体、算账体。
- **批量造金句法**：用「XX 就是 XX」四字命名（嘴甜=招财、请客=买路、让利=搭桥、借钱=筛人），把干货打包成可转发的记忆点。
- **选题复用**：高流量选题会反复打磨（如「六种钱」与「七种最好赚的钱」同源）。

## 三、逐条拆解的 4 个维度（每条视频都填）

| 维度 | 内容 |
|---|---|
| 开头钩子 | 前 3 秒用了什么（设问/极限数字/权威背书/反常识/真人对话），原文摘录 |
| 内容结构 | 分几段、每段作用、递进关系 |
| 金句 | 最值得抄的一句（可传播的命名/比喻/对仗） |
| 拆解观察 | 这条为什么有效、 targeting 谁、在漏斗里的作用 |

## 四、引流漏斗分析（每条视频结尾必看）

- 结尾是否有**统一转化尾板**：「我是XX + 点击预约进群 / 扣关键词领资料 / 12条收入管道送给你」。
- 记录引流钩子词（关键词、资料名、进群话术）——这是账号真正的变现落点。
- 分析漏斗：内容引流 → 私域沉淀 → 训练营/课程交付 → 分成/佣金。

## 五、同类账号对比（五维法）

任何对标账号过五维：**IP定位 → 流量来源 → 产品体系 → 商业模式 → 是否值得复制**。
- 对比表列：账号 / 粉丝·作品 / 定位与变现 / 与目标账号的差异。
- 结论要落到：这条赛道的天花板由「信任状 + 产品化」决定；真实一手案例是最强护城河。

## 六、给委托方的可借鉴点（回答「怎么变成钱」）

- 真实一手案例 → 护城河；
- 方法论命名化 → 可命名、可收藏的工具；
- 双管道叙事（如线下+线上）；
- 警示：情绪话术/玄学咒语、高价课的交付与合规风险。
- 老板底线：任何建议必须能回答「这条路径怎么变成钱」。

## 七、写作红线

- 写稿只用老板本人原话；他人诊断类表述必须标注「待确认」。
- 收入/房源等数字严禁编造——没有真实数字就标【待补】。
- 价格/参数写给别人前必须当天核实（老板 2026-10-26 明确要求）。
